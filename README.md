## 先分清：澳洲VPS的四类需求，别买错 IP

澳洲VPS的搜索量不小，但搜的人要的东西完全不一样。有人要澳洲本土 IP 做账号，有人要悉尼机房给本地客户访问，有人只是想把一台机器放在澳洲做落地，还有人误以为澳洲机房能当低延迟回国节点。先对号入座，再谈配置。
